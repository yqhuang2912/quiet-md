# 文档库位置

个人版在 Windows 安装时或便携版首次启动时询问文档库位置。新库保持空白。文档库可建在本机，也可以使用操作系统中已挂载的 NAS 共享目录。

## 在 NAS 上保存笔记

1. 在 Windows 资源管理器或 macOS 访达中连接 NAS 共享。建议在共享中专门建一个文件夹存放笔记。
2. 在「设置 → 文档库 → 更改位置…」选择该文件夹。应用会先保存打开的笔记，然后重启并在所选位置打开文档库。
3. 在另一台设备上连接同一共享，再选择同一个文件夹。建议使用同一代客户端，并避免同时编辑同一篇笔记。

文档和文件夹按标题存放在所选目录中，附件在 `.assets/`，文档库索引和回收站在 `.quiet/`。旧版文档库仍由上游迁移流程处理。已启用的文档库不可访问时，应用会报告错误，原位置设置可在共享重新连接后继续使用。

## 把已有文档库复制到 NAS 或其他文件夹

在「设置 → 文档库 → 复制到…」选择已有的空文件夹，点击「迁移并重启」。应用在复制前保存所有窗口，复制文档、附件、回收站和库内设置，随后打开目标文档库。原目录保留。复制失败时继续使用原目录，可在设置中取消或重试。本机外部 Markdown 文件保留原位置。

文档库位置是设备设置，保存在本地应用数据目录的 `io.github.yqhuang2912.mynote/library.json`。每台设备分别选择自己的挂载路径。测试用 `QUIET_MD_HOME` 指定临时文档库，用 `QUIET_MD_CONFIG_HOME` 指定临时位置设置目录。
