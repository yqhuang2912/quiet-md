# 自定义文档库文件夹

首次安装 Windows 版时，安装向导会单独询问「文档库位置」，与程序安装文件夹分开。macOS ZIP 和便携版在首次启动时显示位置确认页面，确认之前不会创建笔记。可以使用默认的 Documents/Quiet.md，也可以选择空文件夹或已有的文档库。选择新的空位置会创建新库，不会搬运之前的测试数据。

位置确认一次后会记住，重新启动和后续升级不重复询问。自动更新采用静默安装时保留已有选择；如果尚未确认位置，则由更新后的应用在启动时询问。卸载程序不删除笔记和位置设置。

新建的文档库保持空白，不自动导入指南、示例或预置文档；只创建保存笔记所需的内部目录和设置文件。已有文档库不会被清空。

从 MyNote 0.2.1 起，在「设置 → 文档库 → 文档库文件夹 → 更改位置…」选择一个已存在的空文件夹，再点击「迁移并重启」。请先退出其他正在使用同一文档库的应用实例；NAS 正在同步时，等同步完成后再重启。

退出前会检查所有窗口是否保存成功。下次启动在打开文档库之前复制完整目录，包括笔记、附件、文件夹、收藏、回收站、偏好设置、自定义主题以及 `.nas-sync` 中的配置和同步记录；不会重新初始化同步关系。本机外部 Markdown 文件仍保留原位置，不会被搬入文档库。

原目录保留作为备份，不自动删除。确认新位置的笔记和同步正常后，可自行整理旧备份。以后也可按同样步骤迁移到另一个空文件夹。该功能用于迁移当前文档库，不合并已有的两个库，也不覆盖目标文件夹里的文件。新旧位置不能相同、互相包含或直接选磁盘根目录。迁移会拒绝符号链接。

复制失败时继续使用原目录并显示提示，待迁移位置仍可在设置中取消或重新选择。新目录已经启用后，如果磁盘断开或目录不可访问，应用会报错；不会在默认目录里新建空库。请选择可长期访问的本机文件夹，跨设备仍使用已有的 NAS 同步功能。

文档库位置是设备设置，保存在系统本地应用数据目录的 `io.github.yqhuang2912.mynote/library.json`，不会经 NAS 同步；Windows 和 macOS 可各自使用不同的文件夹。`QUIET_MD_HOME` 环境变量优先，用于开发或临时指定文档库；设置了它时，界面不修改持久位置。

应用同时记住已迁移过的旧位置，让文档中原有的绝对图片和附件路径指向新副本；不需要改写笔记正文或重置 NAS 同步基线。这些旧位置映射同样只保存在当前设备的位置设置中。

本版起新插入的图片、封面和附件保存为 `assets/...` 相对路径，文档库可完整复制到其他目录或经 NAS 同步到不同系统。

测试必须使用临时文档库。`QUIET_MD_CONFIG_HOME` 可将位置设置文件单独放到测试目录，避免触及设备的真实设置；正式使用不需要设置它。
