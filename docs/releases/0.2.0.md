# MyNote 0.2.0

基于 Quiet.md 0.1.9 的首个个人版本，个人改动在 `yqhuang2912/quiet-md` 维护。

- NAS 同步：Windows/macOS 使用同一套同步协议，通过 Tailscale 访问自己的 Docker 服务，包含笔记、文件夹、附件和回收站。修复持续输入时可能产生的同设备误冲突。
- 慢变量正文样式：可单独启用图片边框、图注和代码配色；表格保留原色并居中。图片在编辑模式下仍可拖动四角缩放。
- 代码自动缩进：Enter 继承已有缩进，Python 冒号和常见左括号后增加一级；已有括号对中间换行时保持右括号层级。Shift+Enter 保留原始换行。
- 个人更新渠道：只检查本仓库 GitHub Releases，通过个人 Minisign 公钥校验安装包，下载与重启安装由用户决定。

首次使用请安装本 Release 的 Windows x64 安装包，或下载 Apple Silicon（M 系列）macOS 应用；不提供 Intel Mac 包。Windows 安装包没有 Authenticode 证书；macOS 使用 ad-hoc 签名，未做 Apple 公证。应用内更新仍会检查个人 Minisign 签名。

配置说明：[NAS 同步](https://github.com/yqhuang2912/quiet-md/blob/mynote/docs/NAS_SYNC.md)、[个人自动更新](https://github.com/yqhuang2912/quiet-md/blob/mynote/docs/PERSONAL_UPDATES.md)。
