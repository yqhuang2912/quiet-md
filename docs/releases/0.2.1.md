# MyNote 0.2.1

- 新文档库从空白开始，不再自动创建开始指南或示例文档。已有文档保持原样。
- Windows 安装向导新增文档库保存位置选择；macOS ZIP 和便携版在首次启动时确认。后续升级保留选择，不重复询问。
- 新插入的图片、封面和附件使用文档库相对路径，支持更换位置和跨平台 NAS 同步。
- 新增自定义文档库文件夹：在「设置 → 文档库」选择空文件夹，点击「迁移并重启」。完整复制笔记、附件、回收站、设置和 NAS 同步记录，原目录保留备份；复制失败继续使用原位置。
- 更新清单迁移到仓库独立的 `updates` 分支。下载包仍固定到本仓库对应版本的 Release，并校验内置公钥的 Minisign 签名。
- Release 仅上传 Windows x64 安装程序与 macOS Apple Silicon ZIP。独立签名、校验和及更新 JSON 不再作为 Release 附件；GitHub 自动生成的两个 Source code 下载链接仍会显示。

**0.2.0 用户请手动安装一次本版**，以后继续在应用内更新。Windows 运行安装程序；M 系列 Mac 解压并替换应用。安装前正常退出旧版，现有默认笔记库会继续使用，无需重新设置 NAS 同步。仅当你在设置里更改位置时才会迁移文档库。

Mac 包使用个人 ad-hoc 签名，未进行 Apple Developer ID 公证，首次启动可能需要在系统设置中允许运行。请从本仓库下载。
