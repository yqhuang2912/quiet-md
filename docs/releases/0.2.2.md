# MyNote 0.2.2

- 修复代码块选中多行后按 `Shift+Tab` 只处理最后一行的问题。现在会统一减少选中行的缩进，保留选区，支持反向选择和撤销重做；`Tab` 也支持选中多行一起缩进。
- 修复 Markdown 表格保存时遗漏图片，以及重新打开时未恢复单元格图片的问题。支持同一单元格中的多张图片及前后文字，导出「所有内容」时也会复制表格图片。
- 修复本地图片文件名含空格、括号或百分号时，保存后的路径无法正确还原的问题。

0.2.1 用户可以在应用的「设置 → 关于」检查更新，下载并重启安装。0.2.0 用户仍需手动安装一次新版，之后即可使用应用内更新。

本版提供 Windows x64 安装程序和 macOS Apple Silicon ZIP。Mac 包沿用个人 ad-hoc 签名，尚未进行 Apple Developer ID 公证。

分栏、高亮块等功能适用于原生笔记；直接编辑或导入后保留为 `.md` 的文档仍会隐藏无法完整保存的功能。软件内新建的原生笔记不受该限制。
