# MyNote 0.2.3

- 更新下载支持断点续传。网络中断后保留已下载内容，连接失败或暂时的服务器错误最多自动尝试 5 次。
- 下载失败后，侧栏可点击「重试」，「设置 → 关于」可点击「继续下载」，无需重新检查更新再从头下载。重启应用后，同一安装包的下载进度也会保留。
- 更新器优先使用代理环境变量，否则读取 Windows/macOS 的手动系统代理设置；macOS 也支持系统 SOCKS 代理。PAC 自动代理脚本暂不在读取范围内。
- 连接超时从 15 秒延长到 60 秒，单次下载允许 30 分钟；连接停滞时自动重连。完整下载后仍校验安装包大小、名称和 Minisign 签名，不安装损坏文件。

**可以从 0.2.1 直接安装 0.2.3，无需先安装 0.2.2。** 文档库位置、笔记和 NAS 同步配置会保留。本版也包含 0.2.2 的代码块多行缩进和 Markdown 表格图片修复。

0.2.2 及之前的应用仍使用旧下载器。如果应用内下载持续失败，请用浏览器从本 Release 手动下载安装一次。本次安装完成后，后续更新就会使用新的续传和代理处理逻辑。实际下载速度仍取决于 GitHub 连接和代理线路。

本版仅提供 Windows x64 安装程序和 macOS Apple Silicon ZIP。Mac 包沿用个人 ad-hoc 签名，尚未进行 Apple Developer ID 公证。
