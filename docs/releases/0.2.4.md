# MyNote 0.2.4

- 合入官方 Quiet.md 0.1.10 稳定版，保留个人版 NAS/Tailscale 同步、自定义文档库、慢变量样式和自动更新渠道。
- 修复查找定位：Ctrl+F / Cmd+F 查找期间点击正文后，「下一个／上一个」会从新光标位置继续，查到末尾后循环；关闭查找会保留新放置的光标。
- 新建菜单支持文档、Markdown 和文件夹，快捷新建可记住上次类型，也可在设置中指定默认类型。
- 宽表格增加可拖动的横向滚动条；Markdown 表格支持按列对齐，保存和重新打开时保留对齐方式，图片单元格也会保留图片和列对齐。
- 长输入框跟随光标滚动，改善链接输入、文件夹新建和重命名体验。

可从 0.2.1、0.2.2 或 0.2.3 直接升级，文档库位置、笔记和 NAS 同步配置会保留。0.2.3 的下载续传、重试及系统代理支持继续保留。较旧版本如果应用内下载失败，可从本 Release 手动下载安装。

仅提供 Windows x64 安装程序和 macOS Apple Silicon ZIP。Mac 包沿用个人 ad-hoc 签名，尚未进行 Apple Developer ID 公证。

本版通过 Windows/macOS 发布检查；发布前还在 Windows 本机通过完整检查及 2000 组随机编辑测试。
