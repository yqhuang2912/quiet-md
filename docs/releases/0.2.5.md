# MyNote 0.2.5

- 合入官方 Quiet.md 0.1.14。文档库使用真实文件夹和以标题命名的文件，新增版本历史和画板。
- 查找替换支持正则与捕获组替换，保留从正文光标继续查找的行为。导入的 Obsidian 双链可以跳转到对应笔记或标题。
- 可分别设置界面字体和文档字体，新增土耳其语和阿拉伯语从右到左排版，并改善大型文档库的搜索和批量删除速度。
- 移除旧的 NAS／Tailscale 测试同步。现在可在「设置 → 文档库 → 更改位置…」打开已挂载的 NAS 共享目录，或用「复制到…」将现有文档库复制过去。旧测试服务中的远端记录不会自动导入。 [文档库位置说明](https://github.com/yqhuang2912/quiet-md/blob/mynote-v0.2.5/docs/LIBRARY_LOCATION.md)

从 MyNote 0.2.4 升级时沿用已选文档库位置。旧布局由应用迁移并保留迁移备份。新文档库保持空白。继续使用个人更新渠道，安装包通过同一套 Minisign 公钥验证。

提供 Windows x64 安装程序和 macOS Apple Silicon ZIP。Mac 包使用个人 ad-hoc 签名。
